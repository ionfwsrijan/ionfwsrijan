## 🚀 Featured Projects

### 🛡️ PatchPilot: AI Security Scanning & Remediation
*An end-to-end DevSecOps platform that finds vulnerabilities in a codebase and helps fix them.*

- Scans GitHub repos and ZIP uploads with **Semgrep (SAST)**, **OSV-Scanner** and **Gitleaks**
- Produces automated remediation suggestions, validated in a sandboxed environment
- Generates downloadable **compliance evidence packs** for audits
- **Stack:** React · Vite · Tailwind · Python backend pipeline

### 🤖 AI Document Q&A (RAG)
*Ask questions of your own documents, answered by an LLM grounded in semantic search.*

- **RAG architecture** built on vector databases and embeddings
- **LangChain + LLM** for accurate, context-aware answers
- REST API for real-time document querying
- Prompt engineering and NLP techniques to improve output quality

### 🌐 Network Security ML System
*Real-time network threat detection with machine learning.*

- Modular pipeline: data ingestion → validation → transformation → training
- Flask web app serving **real-time threat predictions**
- **Stack:** Python · Scikit-learn · Pandas · NumPy

### 📉 Customer Churn Prediction
*Identify customers likely to leave, before they do.*

- Full pipeline with **Logistic Regression, Random Forest and XGBoost**
- EDA, feature engineering and evaluation on F1, precision and recall
- Applicable to telecom, streaming and SaaS businesses
